# 极简数图工具箱 (DIP Toolbox)

纯原生 HTML / JS 构建的本地图像处理工具箱。无需后端、无需安装、无需联网，所有图片处理都在你自己的浏览器里完成。

> 一个单文件网页，把「查快捷键 / 压图 / 取色 / 抠图 / 调色 / 滤波 / 拿渐变代码」这几件小事收在一处，顺带把 PS 黑话翻译成人话。

适合：写前端时临时压图取色、给项目切个透明图、不想为了一个快捷键翻半天 Photoshop 的人。

## 特性

界面分三个页签：

### 01 · 查询百科

- **30 个高频 PS 快捷键**速查，支持按名称或组合键搜索（试试「盖印」或 `Ctrl+J`），点一下卡片直接复制。
- **格式对照表**：JPG / PNG / WebP 三者的优点、短板与适用场景一览。

### 02 · 进阶实操

七个纯前端工具，全部基于 Canvas 2D 逐像素计算：

| 工具 | 说明 |
| --- | --- |
| 图片压缩 / 格式转换 | 质量 10–100 可调，输出 JPG 或 WebP，带原图/压缩后拖动对比与 RGB 直方图 |
| 图片取色器 | 点图取色，即时显示 HEX / RGB，一键复制 |
| 图层混合实验室 | 两张图叠加，支持正片叠底、滤色、叠加、正常四种混合模式 |
| 容差抠图模拟器 | Flood Fill 连续区域抠图 + 软阈值羽化 + 反选，导出保留透明通道的 PNG |
| 高级色彩调校 | R / G / B 三通道 −100 ~ +100 独立加减，结果以原图为基准、不累积 |
| 图像空域滤波 | 3×3 均值滤波（平滑去噪）与拉普拉斯锐化（边缘增强），可下载结果 |
| 极简 CSS 渐变 | 两色 + 角度，实时预览并复制 `linear-gradient()` 代码 |

### 03 · 急救与灵感

- **神仙配色库**：成组配色方案，点整张卡片一次复制该方案的 6 个色号。
- **避坑指南**：RGB 与 CMYK、非破坏性编辑、导出尺寸等常见坑的通俗解释。

另外页面上还有：

- **新手完全指南**（可折叠）：按「日常开发 / 图像处理学习 / 隐藏黑科技」三部分整理的使用说明。
- **学习进度条**：随操作推进并保存在本机，可一键重置。
- **截止倒计时**：可自定义目标时间，自动保存在本机。属于可选装饰卡片，不需要的话删掉 HTML 中 `#countdownCard` 那一段的同时，还要一并移除脚本里的 `updateCountdown` / `deadlineInput` 相关绑定，否则初始化会报错。
- **小彩蛋**：连点右上角问候语 5 次。

## 快速开始

不需要 Node、不需要构建、没有依赖。

```bash
# 方式一：直接双击 index.html（file:// 下所有工具都能用，仅 PWA 安装不可用）

# 方式二：起个本地静态服务器，PWA 与 Service Worker 才能生效
python -m http.server 8000
# 然后打开 http://localhost:8000
```

任选其一即可，两种方式下图片处理功能都完整可用。用本地服务器方式访问过一次之后，Service Worker 会把页面缓存下来，此后断网也能打开。

## 安装为 PWA

用 `https://` 或 `localhost` 打开页面后：

- **Chrome / Edge**：地址栏右侧的「安装」图标，或菜单 → 应用 → 安装此站点。
- **Android**：菜单 → 添加到主屏幕。
- **iOS Safari**：分享 → 添加到主屏幕。

安装后以独立窗口运行，离线可用。

## 部署

整个项目就是一组静态文件，把仓库根目录直接丢给任意静态托管即可：

- **GitHub Pages**：Settings → Pages → 选择分支与 `/ (root)`。
- **Netlify / Vercel / Cloudflare Pages**：构建命令留空，发布目录填 `.`。
- 自有服务器：把文件放到任意目录，确保同源即可。

> PWA 与 Service Worker 要求 HTTPS（`localhost` 例外），部署到 Pages 之类的服务默认已满足。

## 实现要点

- **零依赖**：没有框架、没有打包器、没有 CDN 请求。断网、内网、`file://` 下均可工作。
- **像素计算用 Canvas 2D**：`getImageData` / `putImageData` 做逐像素处理，`toBlob` 导出。
- **大图降采样**：所有重算法都先缩到离屏画布再算 —— 抠图长边 800px（显示与导出上限 1600px），调色 1000px，滤波 600px，避免卡住主线程。
- **连续区域抠图**：BFS 洪水填充，`visited` 在入队前置位，每个像素最多入队一次，不会死循环；颜色距离落在容差边缘时输出渐变 alpha，得到 1–2px 的柔和边缘。
- **本地存储**：学习进度、倒计时时间只写 `localStorage`，不上传任何数据。
- **离线缓存**：`sw.js` 采用 Cache First，导航请求失败时回退到缓存的 `index.html`。

## 隐私

**图片只在你的浏览器内存里处理，不会上传到任何服务器。** 页面不加载第三方脚本、不做埋点统计、不发网络请求（Service Worker 的缓存读写除外）。

## 浏览器兼容

面向支持 ES2020 与 Canvas 2D 的现代浏览器：

- Chrome / Edge 90+
- Firefox 90+
- Safari 15+（`toBlob` 与 `cache` API 均已支持）

`file://` 打开时 Service Worker 不注册，其余功能正常。

## 已知限制

- 抠图导出的长边上限是 1600px，不是原始分辨率（按显示画布导出，兼顾内存与速度）。
- 单个文件上限 25MB；格式支持 JPG / PNG / WebP。
- 抠图在低容差下可能保留 1px 的半透明边缘过渡像素（matte fringe），提高容差即可收掉，属正常现象。
- 图标的位图版本按固定配色预生成，改主题色后需要同步重新导出 PNG。

## 修改后请注意

改过页面内容后，记得把 `sw.js` 里的缓存版本号 +1：

```js
const CACHE_NAME = "dip-toolbox-pwa-v5";  // v5 → v6
```

否则已安装过的用户会继续命中旧缓存，看不到更新。
